# Web Fetch MCP Module

- **Package**: `mcp-server-fetch` (Official Model Context Protocol)
- **Runtime**: Python 3.14 venv (`~/Developer/AI-Dev-Team/environments/mcp-env/bin/python`)
- **Transport**: Stdio (JSON-RPC 2.0)
- **Runner**: `~/Developer/AI-Dev-Team/mcp/web/run.sh`

## Capabilities (1 Tool)
- `fetch`: Fetches web content via HTTP request, extracts core textual content, and converts HTML into clean Markdown without executing JavaScript.

## Purpose
- Fast documentation reading, reference lookups, static API documentation parsing, and web research without browser overhead.
